# Reflection

## 1. How did AI support the documentation process?

ChatGPT helped me organize my R project documentation and create a clear structure for the README and R Markdown files. It suggested headings, bullet points, code examples, and an AI assistance declaration. This gave me a starting point for preparing professional project documentation.

## 2. What were the limitations or risks of using AI?

AI-generated content may contain errors or code that has not been tested. The documentation may also describe something that does not work as expected. I learned that I should not rely only on AI-generated answers. I need to run the code, check the output, and review the formatting before submitting my work.

## 3. How did you verify and improve the AI-assisted output?

I ran the `student_performance.R` script in RStudio and checked the synthetic student data, summary statistics, and bar chart. The average score displayed was 83.2. I also knitted the `student_performance.Rmd` file and previewed the `README.md` file to check that the headings, lists, and code blocks displayed correctly. I reviewed the project files and identified the need to check the documentation and remove draft instructions before submission.
